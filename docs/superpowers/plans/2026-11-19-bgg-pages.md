# BGG Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add four BoardGameGeek pages (H-index, recent plays, top played, year stats) to the Pixoo rotation.

**Architecture:** `bgg.py` fetches/parses BGG plays and computes H-index data; `bgg_render.py` draws 64x64 frames reusing helpers from `render.py`; `update.py` gets BGG as a third source with a page selector.

**Tech Stack:** Python 3.10+, requests, Pillow, unittest (run via `uv run pytest`).

**Spec:** `docs/superpowers/specs/2026-11-19-bgg-pages-design.md`

## Global Constraints

- Frames are 64x64 RGB `PIL.Image`; text via `retro_pixoo/font.py`; no resizing needed (no images).
- BGG auth: header `Authorization: Bearer $BGG_TOKEN`; the token is never printed or stored in the repo.
- BGG username default `Kelsin`; year = current calendar year.
- H-index sums `quantity` per game (`game_id`); largest h with h games >= h plays. Expansions are separate games.
- Commit messages are Conventional Commits; no attribution lines beyond what the repo reminder requires.
- Existing `collect_pages(ra, lb, fetcher)` callers/tests must keep working unchanged.

## Review Focus

- Zero plays this year: every page renders a "NO PLAYS" style frame, no crash, h=0.
- Missing `length`/`quantity` attributes or `length="0"`: quantity defaults 1; hours line hidden when no play has minutes.
- Paged results (`total` > 100): client fetches every page and merges.
- Missing/empty `BGG_TOKEN` or HTTP 401/202: clear error message, only BGG pages skipped.
- Very long game names: truncated with `font.fit`, never overflow 64px.

### Task 1: BGG data module

**Files:**
- Create: `retro_pixoo/bgg.py`, `retro_pixoo/sample_plays.xml`, `tests/test_bgg.py`

**Interfaces:**
- Produces:
  - `@dataclass Play(date: str, game: str, game_id: int, quantity: int, minutes: int)` (`date` is `YYYY-MM-DD`)
  - `parse_plays(xml_text: str | bytes) -> list[Play]`; `parse_total(xml_text) -> int` (the `total` attribute)
  - `class BggClient(token: str | None = None, timeout: float = 10.0)` with `plays(user: str, year: int) -> list[Play]`; token defaults to `os.environ["BGG_TOKEN"]`, raising `RuntimeError("BGG_TOKEN not set")` if absent; raises on non-200 (including 202/401) with status in the message; pages 100 at a time until `total` plays are collected
  - `load_sample_plays() -> list[Play]` (sample_plays.xml: ~25 plays in 2026 across ~10 games, one with `length="0"`, one with no `quantity`, plus one 2025 play)
  - `game_counts(plays: list[Play]) -> list[tuple[str, int]]` sorted by count desc then name
  - `h_index(plays: list[Play]) -> int`
  - `h_next(plays: list[Play]) -> tuple[int, int, str | None]` = (h, extra plays needed to reach h+1, first game name needing a play): take the top h+1 games by count, each needs `max(0, h+1 - count)`; missing games (fewer than h+1 distinct) need `h+1`; name is the first needing >0 or None
  - `top_played(plays, n: int = 5) -> list[tuple[str, int]]`

### Task 2: BGG page renderers

**Files:**
- Create: `retro_pixoo/bgg_render.py`, `tests/test_render_bgg.py`

**Interfaces:**
- Consumes: `Play`, `h_index`, `h_next`, `top_played`, `game_counts` from Task 1; `SIZE, BG, WHITE, GREY, GOLD, CYAN, DIM, _header, _bar` from `retro_pixoo.render`; `retro_pixoo.font` (`draw_text`, `text_width`, `fit`).
- Produces (all `-> Image.Image`, 64x64 RGB, taking `today: date | None = None`, filtering to `today.year`; the 2026 H-index header reads `H-INDEX 2026`):
  - `bgg_h_frame(plays, today=None)`: header; `H=` number at `scale=3` centered; `_bar` showing progress `(sum of min(count, h+1) over top h+1 games) / (h+1)^2`; line `N MORE PLAYS` and below it the `font.fit`-ed name from `h_next`; when 0 plays: `NO PLAYS`.
  - `bgg_recent_frame(plays, today=None, count=4)`: header `RECENT PLAYS`; rows newest first (stable by date desc): fitted game name left, `MM/DD` right, `x2` suffix style marker if quantity > 1; `NO PLAYS` when empty.
  - `bgg_top_frame(plays, today=None)`: header `TOP PLAYED`; five rows `rank name count` with a thin `_bar` under or beside scaled to the max count.
  - `bgg_stats_frame(plays, today=None)`: header `<YEAR> STATS`; lines `PLAYS n`, `GAMES n` (distinct), `HOURS n` only if total minutes > 0; bottom bar chart of plays per month (12 bars, current month in GOLD, others CYAN, empty months DIM), same style as `month_stats_frame`.

- [ ] **Step 2: Run** `uv run pytest tests/test_render_bgg.py -v` — expect FAIL.

### Task 3: Wire BGG into update.py

**Interfaces:**
- Consumes: Task 1 `BggClient`, `load_sample_plays`, `Play`; Task 2 four frame functions.
- Produces:
  - `BGG_PAGES = {"h": bgg_h_frame, "recent": bgg_recent_frame, "top": bgg_top_frame, "stats": bgg_stats_frame}`

Live mode enables BGG only when `BGG_TOKEN` is set; if unset, print `bgg: BGG_TOKEN not set` to stderr, skip the pages, exit code 1 like other source failures. `--sample` uses `load_sample_plays`.
